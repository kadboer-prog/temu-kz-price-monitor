# Temu KZ Price Monitor

Temu Kazakhstan тауарларының бағасын күніне 2 рет автоматты түрде тексеретін жоба.

## Жоба не істейді

- GitHub Actions арқылы серверде автоматты іске қосылады; ноутбук қосулы болуы шарт емес.
- Әдепкі тексеру уақыты: Asia/Almaty бойынша шамамен 09:00 және 21:00.
- Қазақстан бағасын ғана қабылдайды: валюта `KZT` және/немесе `₸` белгісі болмаса, нәтиже сақталмайды.
- Өнімнің әр сақталған нұсқасын (variant) жеке тарихпен сақтайды.
- Тауар бағасы өзгерсе, `data/prices.json` файлына жаңа өлшем қосылады.
- Бағаның бастапқы/жеңілдіксіз құны емес, бетте көрсетіліп тұрған ағымдағы сату бағасы жазылады.

## Маңызды шектеу

Temu бағасы JavaScript арқылы рендерленуі мүмкін және variant таңдалғанда бөлек жаңаруы мүмкін. Сондықтан монитор Playwright/Chromium қолданады. Вариантты таңдағаннан кейін DOM-дағы ағымдағы бағаны оқиды.

Алғашқы нұсқада anti-bot/логинді айналып өтетін механизм жоқ. GitHub Actions-та Temu браузерді бұғаттаса, монитор сол тексеруді `skipped` деп белгілейді.

## Орнату

1. Осы репозиторийге файлдарды жүктеңіз.
2. `.github/workflows/monitor.yml` ішіндегі `permissions: contents: write` жолын өзгертпеңіз.
3. `data/products.json` файлына бақыланатын өнімдерді қосыңыз немесе кеңейтім арқылы қосыңыз.
4. GitHub → Settings → Actions → General → Workflow permissions бөлімінде `Read and write permissions` таңдалғанын тексеріңіз.
5. Actions → Temu KZ Price Monitor → Run workflow арқылы бірінші тестті қолмен іске қосыңыз.

## Өнім форматы

```json
[
  {
    "id": "607550149868300",
    "url": "https://www.temu.com/...html",
    "title": "Example product",
    "variants": [
      {
        "key": "Black / 64GB",
        "options": ["Black", "64GB"]
      }
    ]
  }
]
```

`variants` бос болса, монитор өнімнің ағымдағы/default нұсқасын тексереді.

## Тарих форматы

```json
{
  "607550149868300|Black / 64GB": {
    "product_id": "607550149868300",
    "variant_key": "Black / 64GB",
    "prices": [
      {"checked_at": "2026-09-17T09:00:00+05:00", "price_kzt": 25409}
    ]
  }
}
```
